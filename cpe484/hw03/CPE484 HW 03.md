## Generate the 1553 Command Words for the Following Transactions (10). Provide the Command Word in Hex.

- RT3, Receive, SA=15, Word Count = 32
	- Address = 3 = 00011
	- Transmit/Receive = R = 0
	- Subaddress = 15 = 01111
	- Word Count = 32 = 00000
	- Result = 0001 1001 1110 0000 = `0x19E0`
- RT3, Transmit, SA=16, Word Count = 32
    - Address = 3 = 00011
    - Transmit/Receive = T = 1
    - Subaddress = 16 = 10000
    - Word Count = 32 = 00000
    - Result = 0001 1110 0000 0000 = `0x1E00`
- RT5, Receive, SA=1, Word Count = 10
    - Address = 5 = 00101

    - Subaddress = 1 = 00001

## Flight Control System for NASA’s Mars Helicopter, Refer to Corresponding PDF (10)

%%
![[CPE484 HW 03 - GripAIAA.6.2019-1289-Mars-Helicopter.pdf]]
%%

- What software framework was used on the copter?
	- The flight control software is implemented in C++ and is structured as a set of callbacks within the F' (F Prime) flight software framework.
	- For the vision processing component residing on the NC, the flight control software makes explicit use of the ARM NEON Single Instruction, Multiple Data (SIMD) framework, which allows simultaneous operations on up to 16 eight-bit pixels by using a set of 128-bit hardware registers.
- What flight computers / boards and architectures were used?
	- Flight Computer (FC): ARM Cortex-R5 microcontroller with dual-core lockstep functionality.
	- Navigation Computer (NC): 2.26 GHz quad-core Qualcomm Snapdragon 801 processor.
		- One core is used for camera image processing.
		- One core is used for the navigation filter.
		- The remaining cores are used for other activity such as logging, radio communication, and command and data handling.
- What operating system(s) were used?
	- The NC runs a non-realtime Linux operating system and communicates with the rest of the system through a UART connection without realtime and reliability guarantees.
- Is the system real-time? Describe aspects of the system
	- The system has real-time elements, but not everything inside the system is real-time. The FC operates in a real-time manner with a 500 Hz control loop to ensure stability.
	- The NC is NOT real-time. To bridge this, the FC uses buffered IMU data to propogate delayed state estimates from the NC to the current time, eliminating latency issues caused by the non-realtime NC.
- Describe an anomaly that has occurred with the copter?
	- If 50 consecutive packets from the NC fail to arrive, the FC switches to a fault response estimator that combines the IMU-propagated state with LRF measurements in a simple observer. At the same time, an emergency landing attempt is triggered, which will cause the vehicle to touch down within a few seconds.
- Describe the communications (RF) pathway from Earth to the Copter.  How do commands from Earth reach the copter? (this might not be in the paper. google it)
	- Commands are sent from Earth via the Deep Space Network (DSN) to the Mars 2020 (Perseverance) Rover, which then relays them to the helicopter via a Zigbee-like UHF radio link; due to signal time lag, the helicopter receives pre-planned waypoints and executes its missions entirely autonomously.
